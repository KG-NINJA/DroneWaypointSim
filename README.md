# dronesim（3Dドローン飛行ルートシミュレーター）

Three.js（CDN）だけで動く、HTML単体のドローン飛行ルートシミュレーターです。  
高度・速度・カメラを切り替えつつ、地面クリックで飛行ルート（ウェイポイント）を編集できます。

## 起動方法
- `dronesim/index.html` をブラウザで開く

補足:
- CDNがブロックされる環境では起動しません（Three.jsを取得できないため）。
- ブラウザ制限や挙動が気になる場合は、ローカルサーバーで配信して開くのがおすすめです。

## できること
- 高度調整（m）: ルート全点の高度(y)を一括変更
- 速度調整: 慣性（加速/減衰/旋回追従）つきでルート追従
- ルート編集:
  - 追加: 地面をクリック
  - 削除: Shift + クリック（近い点を削除、最低2点は維持）
  - 移動: ウェイポイントをドラッグ
- ルート可視化: ウェイポイント球 + 青ライン
- 視認性: グリッド、影、ランドマーク（ビル風）で地面の情報量を追加

## 操作方法（UI）
右上の「コントロール」パネルから操作します。

- 高度 (m): スライダー/数値入力
- 速度: スライダー/数値入力
- カメラ:
  - 俯瞰: 上空から全体を見る
  - ドローン視点: **機体の2m真上**から見下ろす（機体も視界に入ります）
- 編集モード:
  - ON: ルート編集（この間は飛行停止）
  - OFF: 設定したルートで飛行開始（切替時に状態をリセットして安定動作）

## ファイル構成
- `dronesim/index.html`: 本体（UI + 3D + ルート編集 + 慣性）
- `dronesim/plan.md`: 進捗メモ
